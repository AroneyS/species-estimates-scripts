# Dropped: rejected analysis paths

Check here before proposing an analysis. Never delete entries. If a path is
reopened, move it back to `ongoing.md` and log why in `verification.md`.

Group entries under `##` headings (e.g. by aim); each entry is a `###` heading.

Entry template:

```markdown
### kebab-case-id

- Was: what the path proposed
- Why dropped: evidence, with results directory
- Reopen if: concrete condition
- Dropped: YYYY-MM-DD, by user | agent
```
